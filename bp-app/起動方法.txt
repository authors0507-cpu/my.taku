  血圧健康管理アプリ（スマホ版）  起動方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このフォルダ（bp-app）はスマホのブラウザで動くWebアプリです。
記録データはスマホ本体（ブラウザ）の中に保存されます。

【一番かんたんな方法：GitHub Pagesで公開する】
  1. このリポジトリのGitHub設定で GitHub Pages を有効にする
     （Settings → Pages → Branch でこのブランチ、フォルダに /bp-app を指定）
  2. 発行されたURL（https://ユーザー名.github.io/リポジトリ名/ など）を
     スマホのブラウザ（Safari/Chrome）で開く
  3. 共有メニューから「ホーム画面に追加」を選ぶとアプリのように使えます
     （オフラインでも起動できます）

【パソコンで試す場合】
  1. コマンドプロンプト・ターミナルで bp-app フォルダに移動
  2. 以下を実行してローカルサーバーを起動

       python -m http.server 8000

  3. ブラウザで http://localhost:8000 を開く
  4. 同じWi-Fiに繋いだスマホから
     http://（パソコンのIPアドレス）:8000 を開いても確認できます
     ※ この方法はホーム画面追加やオフライン動作が不安定な場合があります。
       本格的に使う場合は GitHub Pages などのHTTPS環境をおすすめします。

【データについて】
  ・記録はスマホ内のブラウザに保存されるため、ブラウザのデータを消すと失われます
  ・「エクスポート(JSON)」で記録をファイルに保存し、
    「インポート」で別の端末やブラウザに読み込むことができます
  ・「エクスポート(CSV)」でExcelなどの表計算ソフトに取り込めます
