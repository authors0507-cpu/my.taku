  せどり 利益計算ツール（Gmail連携版）  起動方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【STEP 1】ライブラリのインストール（初回のみ）
  コマンドプロンプトで以下を実行：

    pip install openpyxl google-auth-oauthlib google-api-python-client

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【STEP 2】Gmail API の設定（Gmail取得機能を使う場合・初回のみ）

  1. https://console.cloud.google.com/ にアクセス（Googleアカウントでログイン）

  2. 画面上部の「プロジェクト選択」→「新しいプロジェクト」を作成
     （プロジェクト名は何でもOK例：sedori-tool）

  3. 左メニュー「APIとサービス」→「ライブラリ」を開く
     「Gmail API」を検索して「有効にする」をクリック

  4. 左メニュー「APIとサービス」→「認証情報」を開く
     「認証情報を作成」→「OAuth 2.0 クライアントID」を選択
     アプリケーションの種類：「デスクトップアプリ」を選択
     「作成」をクリック

  5. 作成されたクライアントIDの「JSONをダウンロード」をクリック
     ダウンロードしたファイルを「credentials.json」という名前に変更して
     このツール（calculator.py）と同じフォルダに保存

  6. 初回「Gmail取得」ボタンを押すとブラウザが開きます
     Googleアカウントで認証するとtoken.jsonが自動作成されます
     ※ 2回目以降はブラウザは開きません（自動で認証されます）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【毎回の起動】
  コマンドプロンプトで以下を実行：

    python calculator.py

  ※ calculator.py があるフォルダで実行してください

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【使い方】

  ■ 仕入れ情報の入力
    1. 購入日・ショップ（楽天 / Yahooショッピング）を選択
    2. 商品名を入力
    3. 仕入れ価格（クーポン込み）と獲得ポイントを入力
       → 実質仕入れ価格が自動計算されます

  ■ 販売情報の入力
    4. 販路（Amazon FBA / Amazon 自己発送 / メルカリ）を選択
    5. 販売日を入力
    6. 販売価格・外注・送料を入力

  ■ 手数料の入力
    【Amazon の場合】
      「Gmail取得」ボタンを押すと最新の注文確定メールを自動で読み込み
      Amazon手数料を自動入力します
      ※ 複数のメールがある場合は選択ダイアログが表示されます

    【メルカリの場合】
      販売価格の10%を自動計算します（手入力不要）

  ■ 結果の確認と保存
    7. 利益額・ROI・利益率が自動計算されます
    8. 「Excelに保存」ボタンで せどり_集計.xlsx に追記されます
       黒字は緑、赤字は赤でセルが色付けされます

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Excelの列構成】
  購入日 / ショップ名 / 商品名 /
  仕入れ価格(クーポン込み) / 獲得ポイント / 実質仕入れ価格 /
  販路 / 販売日 / 販売価格 /
  外注 / 送料 / 手数料 /
  利益額 / ROI / 利益率
