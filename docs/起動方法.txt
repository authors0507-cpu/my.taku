  血圧健康管理アプリ（スマホ版）  起動方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このフォルダ（docs）は GitHub Pages で公開するための配布用コピーです。
中身は bp-app フォルダと同じです。修正するときは bp-app 側を編集し、
このフォルダにも同じ内容をコピーしてください。

記録データはスマホ本体（ブラウザ）の中に保存されます。

【GitHub Pagesを有効にする（最初の1回だけ）】
  1. GitHubでこのリポジトリを開く
  2. Settings → Pages を開く
  3. 「Build and deployment」の Source を「Deploy from a branch」にする
  4. Branch でこのアプリがあるブランチを選び、フォルダは「/docs」を選択して Save
     ※ mainブランチに取り込んだ後は、Branchをmainに変更してください
  5. 数分後、https://ユーザー名.github.io/リポジトリ名/ で公開されます

【スマホで使う】
  1. 発行されたURLをスマホのブラウザ（Safari/Chrome）で開く
  2. 共有メニューから「ホーム画面に追加」を選ぶとアプリのように使えます
     （オフラインでも起動できます）

【データについて】
  ・記録はスマホ内のブラウザに保存されるため、ブラウザのデータを消すと失われます
  ・「エクスポート(JSON)」で記録をファイルに保存し、
    「インポート」で別の端末やブラウザに読み込むことができます
  ・「エクスポート(CSV)」でExcelなどの表計算ソフトに取り込めます
